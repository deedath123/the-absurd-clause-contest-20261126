## Entry

> By accepting these terms, the user agrees that, upon termination, the company may repossess the user's refrigerator light and mail it to the user's mother with a handwritten apology.

## How it works

`main.py` (Python 3.13, standard library only) writes the single-sentence entry to `/output/entry.txt`.

Run it with:

```sh
python3 -P -s main.py
```
